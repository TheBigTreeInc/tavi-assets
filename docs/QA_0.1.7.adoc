= QA 0.1.7 — Shared game-developer consumer contract and evergreen README
:toc:

== Bounded pass: TA-020

This is a source-only candidate to let other game developers prototype against one Tavi Assets consumer SDK without making separate asset managers. It introduces granted cross-pack pack/object discovery and per-slot media resolution in the portable JavaScript runtime, plus a fixture host and example. It does not add untrusted asset-pack scripts or production asset-host methods to Tavi.

== Contract decisions

* `tavi.assets/v1` remains a proposed feature, negotiated before use; unsupported Tavi host APIs reject.
* `assets.packs.list` and `assets.objects.discover` search only installed content granted to a trusted caller session; no storefront ownership search is implied.
* `assets.composition.resolve` returns resource bytes for individually checked slots. It does not render/merge artwork, enforce game rules or create a new priced object.
* `rarity` remains optional game-owned metadata and is not a universal marketplace axis. Absent rarity no longer defaults to `common` in validation/query output.
* Proposed bundle and storefront offer schemas describe desired customization/content and display prices. They cannot authorize Wallet spending, ownership or variant entitlements. Those checks are not implemented yet.
* README.md now presents evergreen project goals, usage and boundaries; version-specific changes are tracked in CHANGELOG.md.

== Author-side validation targets

* `python tools/check.py` executes the Python tests, Node consumer/runtime/developer tests, and runnable game demos.
* `node tests/developer_contract_smoke.mjs` checks cross-pack discovery and composition, spoofed grant rejection, capability filtering and no Wallet operations.
* `tests/test_developer_contract.py` checks doc contracts, optional rarity and JSON Schema when the optional `jsonschema` Python module is installed (otherwise the schema-specific checks are skipped, not passed).
* `tools/verify_contracts.py` checks manifest, original task IDs, plan references and source files outside protected ZipRunner paths.
* `docs/architecture/workspace.dsl` has a source-grounded C4 Level 3 update; Structurizr CLI parsing is not proven by file presence alone.
