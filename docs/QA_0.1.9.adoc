== Failure reproduced and repair scope

Prior cross-project review confirmed that `TrustedAssetHostBridge` accepted independent `packs:[]` and `capabilities:[]` arrays. If A granted `card.back` and B granted another capability, the cross product of the arrays could expose B's `card.back` despite no B-specific approval. This repair replaces that model with TaviX 0.1.11 host-only `tavix.asset-grants/v1` projections and a separately supplied verified manifest/digest context. It makes pack-specific checks for resource bytes, metadata, collections, preferences, composition and dependency readiness. A copied official extension ID alone never authorizes asset access.
