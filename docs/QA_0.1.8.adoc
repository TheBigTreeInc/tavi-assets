== Scope

Bounded TA-021 source-only implementation: versioned feature-level required/optional asset declaration schema, numeric semver ranges, optional pack targeting, deterministic host-only readiness checks against grant-filtered installed content, separate SDK feature negotiation and fixture tests. Source project is Tavi Assets only; Atrium, Klondike, TaviX and Social implementations were not modified.

== Automated evidence

`python tools/check.py` executes the preexisting source suite plus `tests/dependency_contract_smoke.mjs`; author-side 0.1.8 source run found 87/87 Python tests and 9/9 focused Node scenarios, along with existing Node tests/demos. JSON Schema draft2020-12 and TypeScript declaration checks were executed separately. The final extracted ZIP verification record is delivered alongside the ZIP.

The proposed dependency resolution deliberately does not implement purchases, user inventory entitlements, downloads, approved manifest binding in TaviX, Social session policies, native platform storage, or automated game launch permission. A missing optional cosmetic must be a normal fallback, not a server fault. Failed/disabled/unowned paid content must remain unavailable by host policy; the local resolver cannot attest such status itself.
