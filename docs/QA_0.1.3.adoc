== Implemented source change: TA-010

* `AssetManager` now serializes initialization/recovery with the same OS-held lock used by installation. The old registry must parse before recovery deletes anything.
* On restart, only scratch names of the exact Python `tempfile.mkstemp()`/`mkdtemp()` form (`.registry-` or `.stage-` plus eight lowercase/digit/underscore characters) are cleaned. Unknown paths are never removed under a guess. Unsafe symlinks reject cleanup.
* A released version directory created by stage rename but not referenced by the atomic registry swap is **not** activated or considered owned; it may be reused by an explicitly approved later install after verification.
* `doctor` exposes bounded recovery counts for an operator on disposable local cache. It is not a production repair or an entitlement API.
* Crash-boundary, invalid registry and cross-process lock tests use `unittest` and a real child process. Linux tests do not prove Windows locking behavior.

== ZipRunner post-update plan

`.ziprunner-post-update-tests.json` declares a non-gating post-readiness command (`python tools/check.py`). It supplies a candidate test definition only; no consumer-executed check receipt exists yet. The pinned public interchange specification documents producer-side source and verification contracts; implementation support must be established independently for the installed ZipRunner version.
