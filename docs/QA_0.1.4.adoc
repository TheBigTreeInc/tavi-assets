== Known limitations

Unknown rulesRef values do not become game effects; the rule engine still requires implementation. No cross-pack collection dependencies or remote signature authority. No Tavi host feature, no native Windows/operator acceptance, no cross-device preference sync, no TaviX release. No source-level editor for building new packs; example artifacts are generated fixtures. Any advertised game compatibility remains proposed until tested in a real game.
