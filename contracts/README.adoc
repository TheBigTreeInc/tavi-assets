= Tavi Assets versioned contracts

The contract directory is the canonical source for data-only pack and proposed host/marketplace formats. A schema is not a trusted publisher signature or a purchase authorization.

* `tavi-assets-pack-v1.schema.json` — implemented manifest shape; binary hash/path/media and graph-reference validation also required.
* `tavi-assets-host-request-v1.schema.json` — proposed `tavi.assets/v1` request shapes; no source path, caller ID or grants accepted.
* `tavi-assets-consumer-v1.json` — negotiated, grant-bound consumer methods including cross-pack discovery and slot resolution; current Tavi hosts do not implement these methods.
* `tavi-assets-portable-runtime-v1.json` — host-owned JavaScript reference service/storage boundary.
* `tavi-assets-customization-bundle-v1.schema.json` — proposed, data-only cross-pack customization slots; no purchase/entitlement effects.
* `tavi-assets-store-offer-v1.schema.json` — proposed untrusted display offers; server-authoritative currency and ownership remain separate.
* `tavi-assets-requirements-v1.schema.json` — proposed TaviX application feature requirements (required/optional capabilities, bounded versions, offline fallbacks).
* `tavix-asset-dependencies-proposal-v1.json` — unapproved TaviX dependency metadata proposal; not live TaviX behavior.
* `tavi-assets-host-proposal-v1.json` — superseded minimal host proposal retained as historical contract context.

See `docs/developer-guide.adoc` for exact API usage and `CHANGELOG.md` for source-version changes. The consumer SDK under `sdk/` is a source reference, not a published or deployed production package.

* `tavi-assets-tavix-grant-adapter-v1.json` — source-referenced TaviX 0.1.11 host input and subset-validation semantics; **not** a second authoritative TaviX grant schema or a production permission token.
